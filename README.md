# DA-AG-013 | SVM & Naive Bayes Assignment

## 📖 Project Overview
This assignment focuses on understanding and implementing two fundamental machine learning algorithms: **Support Vector Machines (SVM)** and **Naïve Bayes classifiers**. The tasks involve theoretical understanding as well as practical implementation using Python and popular datasets. 

The assignment covers:  
- Key concepts and variations of SVM and Naïve Bayes  
- Model training, evaluation, and hyperparameter tuning  
- Working with datasets like Iris, Breast Cancer, Wine, and synthetic text datasets  

## 🛠 Skills Learned
During this assignment, I gained hands-on experience in:  

### 1. Support Vector Machine (SVM)
- Understanding **SVM theory**, including hyperplanes, support vectors, and margins  
- Differentiating between **Hard Margin and Soft Margin SVM**  
- Using the **Kernel Trick** for non-linear data separation  
- Implementing **SVM in Python** with sklearn  
- Performing **hyperparameter tuning** with `GridSearchCV`  

### 2. Naïve Bayes
- Understanding the **Naïve Bayes classifier** and why it is called "naïve"  
- Exploring different variants: **Gaussian, Multinomial, and Bernoulli Naïve Bayes**  
- Applying Naïve Bayes to both **numeric and text data**  
- Generating and interpreting **classification reports** (Precision, Recall, F1-score)  
- Evaluating models using **ROC-AUC metrics**  

### 3. Data Handling & Preprocessing
- Loading datasets using `sklearn.datasets` and CSV files  
- Handling **text vectorization** for NLP tasks  
- Dealing with **class imbalance** in datasets  
- Managing **missing or incomplete data**  

### 4. Model Evaluation
- Calculating **accuracy, precision, recall, F1-score, and ROC-AUC**  
- Understanding **business implications** of predictive modeling  

## 🎯 Outcomes
By completing this assignment, I was able to:  
- Build and evaluate SVM and Naïve Bayes models on multiple datasets  
- Tune model hyperparameters to improve performance  
- Apply machine learning models to real-world problems such as **spam email detection**  
- Gain confidence in **both theoretical concepts and practical implementation** of supervised learning algorithms
